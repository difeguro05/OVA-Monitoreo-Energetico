01

¿Qué es el monitoreo energético?

El monitoreo energético es el proceso de medir, registrar y analizar el consumo de energía eléctrica de un sistema. Permite saber cuánta electricidad se está usando, cuándo se usa y dónde se está yendo.

Es como el velocímetro de un carro, pero para la electricidad de tu casa o empresa.

Hogares

Detectar qué electrodoméstico consume más energía y reducir la factura de luz.

Industrias

Monitorear máquinas para detectar fallas, optimizar procesos y evitar paros inesperados.

Hospitales

Garantizar suministro estable de energía para equipos médicos críticos.

¿Por qué medir?

Lo que no se mide no se puede mejorar. Medir energía es el primer paso para ahorrarla.

02

Conceptos básicos de electricidad AC

Voltaje en corriente alterna (AC)

El voltaje es la fuerza que empuja a los electrones a través de un cable. Se mide en Voltios (V). En la corriente alterna, este voltaje no es constante: cambia de dirección varias veces por segundo, formando una onda senoidal.

En Colombia y la mayoría de países de América, la red eléctrica doméstica trabaja a 120 V / 60 Hz, lo que significa que la onda completa sus 60 ciclos cada segundo.

Onda senoidal de voltaje AC — 120V / 60Hz
● Voltaje (V) — Un ciclo completo = 1/60 s ≈ 16.7 ms

Corriente eléctrica en AC

La corriente es el flujo de electrones que circula por el cable. Se mide en Amperios (A). Al igual que el voltaje, en AC también es alterna: oscila en la misma frecuencia pero puede tener un desfase respecto al voltaje, dependiendo del tipo de carga.

Voltaje y corriente AC — con desfase de fase (carga inductiva)
● Voltaje (V) ● Corriente (A) ← Desfase φ → La corriente llega "tarde" respecto al voltaje
¿Qué significa el desfase? En cargas puramente resistivas (bombillos, estufas), la corriente y el voltaje están perfectamente alineados. En cargas con bobinas o motores (carga inductiva), la corriente se "atrasa". Esto afecta la eficiencia del sistema y se llama factor de potencia.

Potencia eléctrica

La potencia indica cuánta energía consume un dispositivo por segundo. Se mide en Watts (W) y se calcula como:

P = V × I Potencia = Voltaje × Corriente

Bombillo LED

~10W — Bajo consumo

Computador

~150W — Consumo moderado

Estufa eléctrica

~1500W — Alto consumo

Aire acondicionado

~2000W — Muy alto consumo

¿Qué es una carga eléctrica?

En electricidad, una carga es cualquier dispositivo que consume energía: un bombillo, un motor, una nevera, un televisor. La carga "resiste" el flujo de corriente y convierte la energía eléctrica en calor, luz o movimiento.

¿Qué es un microcontrolador?

Un microcontrolador es un pequeño computador en un solo chip. Tiene procesador, memoria y pines de entrada/salida integrados. Se programa para leer sensores, procesar datos y enviarlos a otro dispositivo.

Piénsalo como el cerebro del sistema: recibe los datos de los sensores, hace los cálculos y los envía a la página web.

01. Dispositivos del Sistema

Estos son los componentes físicos que forman el sistema de monitoreo. Cada uno cumple una función específica y se comunica con el ESP32.

CEREBRO DEL SISTEMA

ESP32-S3

El ESP32-S3 es el microcontrolador principal. Lee los sensores, calcula los valores eléctricos y los envía al navegador por USB.

¿Qué es un GPIO? General Purpose Input/Output — es un pin del microcontrolador que puede leer o escribir señales eléctricas. Este sistema usa pines GPIO para leer los sensores.
¿Qué es ADC? Analog to Digital Converter — convierte una señal de voltaje analógica (continua) en un número digital. El ESP32-S3 tiene ADC de 12 bits: puede representar 4096 niveles de voltaje.
Los pines de los sensores pueden cambiarse a cualquier pin que sea ADC. No todos los GPIO tienen ADC — verificar siempre el pinout del ESP32-S3.
SENSOR DE VOLTAJE

ZMPT101B

Mide el voltaje de la red eléctrica AC (127V o 220V) y lo transforma a un nivel seguro (0–3.3V) que el ADC del ESP32 puede leer directamente, sin necesidad de divisor de tensión externo.

Funciona como un transformador miniatura con acondicionamiento interno: aísla galvánicamente la red eléctrica del microcontrolador y entrega la señal escalada por su potenciómetro de ajuste.

ACS712

Mide la corriente que circula por un conductor usando el efecto Hall: detecta el campo magnético generado por la corriente sin contacto directo con el circuito de carga.

El cable de fase de la carga pasa por los terminales IP+/IP- del sensor. El ESP32 lee la salida OUT.

03. Código del Firmware

El firmware es el programa que corre dentro del ESP32. Está organizado en bloques independientes para que puedas entender cada parte por separado.

01 Configuración y Calibración
firmware_esp32s3.ino — Pines y Calibración
// ── PINES ─────────────────────────────────
#define PIN_V  5    // GPIO5 → ZMPT101B (ADC1)
#define PIN_I  4    // GPIO4 → ACS712   (ADC1)

// ── CALIBRACIÓN VOLTAJE ────────────────────
const float VOLTAGE_OFFSET = 1918.0f; // Centro ADC sin señal AC
const float VOLTAGE_FACTOR = 0.19558f; // Escala counts → Voltios

// ── CALIBRACIÓN CORRIENTE ──────────────────
const float CURRENT_OFFSET      = 1942.0f; // Centro ADC sin carga
const float CURRENT_SENSITIVITY = 0.100f;  // ACS712-20A: 100mV/A

VOLTAGE_OFFSET: El ZMPT101B sin señal AC produce exactamente la mitad del voltaje de alimentación en su salida. Este valor (en cuentas ADC) se resta antes de calcular el RMS.

VOLTAGE_FACTOR: Factor de escala que convierte el valor numérico del ADC a voltios reales. Se obtiene calibrando con un multímetro.

CURRENT_SENSITIVITY: El ACS712-20A produce 100mV por cada Amperio de corriente. Dividir el voltaje medido entre este valor da la corriente en Amperios.

02 Cálculo de Voltaje y Corriente RMS
calculateRMS()
// Tomar 1000 muestras a 1kHz (~1 segundo)
for (int i = 0; i < 1000; i++) {
    double v = analogRead(PIN_V) - VOLTAGE_OFFSET;
    double c = analogRead(PIN_I) - CURRENT_OFFSET;
    sumV2 += v * v;  // Acumular cuadrados
    sumI2 += c * c;
    delayMicroseconds(1000);
}
// RMS = raíz cuadrada del promedio de cuadrados
float vRms = sqrt(sumV2 / 1000) * VOLTAGE_FACTOR;
float iRms = (sqrt(sumI2 / 1000) * (3.3/4095.0)) / CURRENT_SENSITIVITY;

¿Por qué RMS? La corriente alterna cambia de dirección constantemente. Si promedias los valores directamente obtienes cero. El RMS (Root Mean Square) eleva al cuadrado, promedia y saca la raíz — esto da el "valor equivalente en DC" que produce el mismo efecto de calentamiento.

1kHz de muestreo: La señal AC es de 60Hz. Para medirla correctamente necesitamos muestrear al menos 2× su frecuencia (Teorema de Nyquist). 1kHz nos da 16 muestras por ciclo — suficiente para un RMS preciso.

03 Cálculo de Potencia
Potencia aparente
// Potencia aparente en Watts
float power = vRms * iRms;

// Umbrales de ruido — evitar lecturas falsas
if (vRms < 10.0f) vRms = 0.0f;   // Sin red = 0V
if (iRms < 0.08f) iRms = 0.0f;   // Sin carga = 0A

P = V × I: La potencia se calcula multiplicando el voltaje RMS por la corriente RMS.

Umbral de ruido: El ADC siempre tiene pequeñas variaciones aleatorias (ruido). Sin este umbral, el sistema mostraría voltajes o corrientes falsas cuando no hay ninguna carga conectada.

Escritura en CSV
// Crear archivo con nombre único
String filename = "/session_" + String(millis()) + ".csv";

// Escribir encabezado
dataFile.println("timestamp_ms,voltage_rms,current_rms,power");

// Cada segundo, guardar una línea

Formato CSV: Los datos se guardan en formato CSV (valores separados por coma), que puede abrirse directamente en Excel o Google Sheets.

Timestamp: Cada lectura incluye el tiempo en milisegundos desde que arrancó el ESP32, permitiendo reconstruir la línea de tiempo del consumo.

Botón CONECTAR ESP32

Abre el diálogo del navegador para seleccionar el puerto USB al que está conectado el ESP32. Requiere Google Chrome o Microsoft Edge. Una vez conectado, los datos llegan automáticamente.

Iniciar Sesión

Crea un nuevo archivo CSV en la microSD y empieza a guardar las lecturas de voltaje, corriente y potencia segundo a segundo. La sesión continúa hasta que presiones FINALIZAR.

Finalizar Sesión

Cierra el archivo CSV en la microSD y detiene el registro. Los datos quedan guardados y pueden consultarse en la pestaña Datos & Estadísticas.

Medidor de Voltaje

Muestra el voltaje RMS de la red eléctrica en tiempo real. En Colombia la red es de ~120V. Si no hay red conectada al sensor, muestra 0V.

Medidor de Corriente

Muestra la corriente RMS que consume la carga conectada al ACS712. Sin carga, muestra 0A. A mayor consumo del dispositivo conectado, mayor corriente.

Medidor de Potencia

Muestra los Watts consumidos (P = V × I). Una bombilla de 60W mostraría ~60W. Una estufa eléctrica puede mostrar 1000W o más.

Osciloscopio

Muestra la forma de onda del voltaje en tiempo real — la señal senoidal de la red eléctrica. Debes activarlo con el botón OSCILOSCOPIO ON. Útil para verificar que la señal es limpia y sin distorsiones.

Serial Log

Registro de toda la comunicación entre el navegador y el ESP32. Muestra los mensajes JSON recibidos, los comandos enviados y los errores del sistema. Útil para diagnóstico.
